# <img src="logo/666.svg" width="30" height="30" /> 海航666-航班/航线交互式地图 <img src="logo/2666.svg" width="30" height="30" />

由于我不是科班出身，也没有系统学过前端开发，代码由 claude / gemini 撰写。比较粗糙，仅为满足个人需求而作。不过考虑到可能对其他人有用，特此整理后发布。如果有大佬想进一步升级，如有需要，可以通过 Issue 或邮件联系我，尽力协助。海航不公布表格数据后，数据更新需要与其他开发者合作，可能时间周期较长，但会不断优化界面。

## ✈️ 功能介绍

本项目包含两个独立功能页，共用同一数据源，均支持移动端适配与深浅色主题。

- **航班地图**  
  全球航线交互式可视化，按实际路径绘制（含经停），以弧线及箭头标示流向。支持按日期、早晚班、航司、机型（大/中/小）筛选；点击任意机场或航线可查看进出港及具体航班详情。
  (在 66666 中，早班定义为：起飞时间 ≤ 09:00 的航班；晚班定义为：到达时间 ≥ 23:00 的航班)
  
- **往返规划器**  
  专为周末短途游设计（周五晚/周六早出发，周日晚返回），或在此基础上请假，输入出发城市即可生成所有满足单程接驳 ≤300 分钟的可往返城市列表，并支持偏好排序。接驳数据仅供参考。

## 🗺️ 地图来源
本项目基于 [Leaflet.js](https://leafletjs.com/) 地图框架构建。中国行政区划边界数据来源于阿里云 [DataV 地理小工具](https://datav.aliyun.com/portal/school/atlas/area_selector)，道路、水系及陆地等基础地理数据来源于 [Natural Earth](https://www.naturalearthdata.com/)。部分早期版本曾使用 [CARTO](https://carto.com/) / [OpenStreetMap](https://www.openstreetmap.org/) / [高德地图](https://www.amap.com/) 提供的开源底图服务，这些版本需要网络加载地图底图。

## ⚠️ 注意事项

- 本地 html 文件所有交互逻辑基于浏览器端运行，无需服务器支持。
- `CN271_cityairport_name_IATA_ICAO_coords.csv` 是自己整理的 中国大陆 271 机场简名-全名-IATA-ICAO-坐标对照表，将持续更新，目前数据截至日期（2026.09.01），来源于CAAC公布的2025年全国民用运输机场生产统计公报。
- 一些数据把起降地写成了起飞城市所在地区，比如“遵义”实际是指的“遵义新舟”，“茅台”是指的“遵义茅台”......可能存在未知的映射错误，欢迎指出。
